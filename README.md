# Shortwave

**Shortwave** is a modern **URL shortener** with built-in tracking and rich analytics.
Designed with a **clean and minimal UI/UX**, it makes shortening, managing, and analyzing links effortless.

## ✨ Features
- 🔗 **Lightning-Fast URL Shortening** – Generate short links instantly.
- 📊 **Advanced Tracking** – Monitor clicks, referrers, devices, and geolocation data.
- 📈 **Interactive Analytics Dashboard** – Visualize link performance with dynamic graphs.
- 🎨 **Minimal & Intuitive Design** – Clean, distraction-free interface.
- ⚡ **High Performance & Scalability** – Built with caching and optimized backend architecture.
- 🔒 **Secure by Design** – Safe and reliable for both personal and production use.

## 🚀 Why Shortwave?
Unlike basic URL shorteners, **Shortwave** gives you **actionable insights** into your audience through real-time analytics.
It’s not just about shorter links—it’s about **making data-driven decisions**.

## 🛠️ Tech Stack
- **Frontend**: React.js + TypeScript + ShadCN UI
- **Backend**: Express.js (Node.js)
- **Database**: MongoDB
- **Cache**: Redis (for performance & scalability)
- **Other**: Charting libraries for interactive analytics
